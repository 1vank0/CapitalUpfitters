# Capital Upfitters Website

Professional website for Capital Upfitters - Rockville's premier truck and fleet customization shop.

## Features

- Modern Next.js 15 with TypeScript
- Tailwind CSS for styling
- Mobile-responsive design
- SEO optimized
- Lead generation focused
- Contact forms and quote requests

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Deployment

This site is configured for standalone deployment and can be deployed to any Docker-compatible hosting platform including the Hostinger KVM VPS.

## Services Covered

- Spray-On Bedliners (Patriot Liner)
- Tonneau Covers

- Lift Kits & Leveling
